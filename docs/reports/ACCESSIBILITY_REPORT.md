# Accessibility Report

MkDocs Material provides keyboard navigation, responsive layouts, contrast-aware light/dark palettes, semantic navigation, focus states, and accessible search. Custom SVG assets include a title where rendered as content, and the responsive table wrapper preserves table semantics.

CI verifies build integrity. A hosted release should additionally run automated WCAG checks and manual keyboard/screen-reader review against the deployed URL.

## Provider Platform Preview

The `v1.4.0` provider dashboard reuses the existing semantic table and status structures and does not add an independent interaction model. Provider health dimensions, compatibility freshness, warnings, and support maturity remain available as text rather than color alone. Release promotion still requires hosted keyboard, screen-reader, zoom, contrast, and automated WCAG evidence for the updated provider views.
