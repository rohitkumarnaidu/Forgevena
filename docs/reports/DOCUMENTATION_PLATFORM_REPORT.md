# Documentation Platform Report

MkDocs Material provides responsive navigation, dark mode, built-in full-text search, syntax highlighting, Mermaid fences, tabs, callouts, code copy, edit links, breadcrumbs, previous/next navigation, Git revision dates, SEO metadata, and Mike version selection.

The site builds from the canonical `docs/` tree. Configuration and pinned dependencies live under `website/`. GitHub Actions independently validate, lint, check links, generate changelog previews, package site artifacts, and publish Pages.

Status: **Implemented; hosted deployment requires enabling GitHub Pages for Actions in repository settings.**
