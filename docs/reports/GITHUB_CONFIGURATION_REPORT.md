# GitHub Configuration Report

Repository identity, topics, website, merge strategy, branch protection, protected environments, security features, and publication secrets are specified in `docs/release/REPOSITORY_SETTINGS.md`. File-controlled settings are implemented through CODEOWNERS, templates, Dependabot, CI, documentation, security, dependency review, package validation, release, Pages, and publishing workflows.

Owner-controlled settings remain pending until explicitly applied in GitHub because they require repository administration privileges.
