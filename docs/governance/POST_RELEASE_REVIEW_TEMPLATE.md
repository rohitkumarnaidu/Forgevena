# Post-Release Review Template

## Release Outcome

Record version, owner, release date, channels, intended value, adoption evidence, task success, compatibility freshness, and support load.

## Verification

Summarize installation, upgrade, rollback, uninstall, documentation, package, security, performance, reliability, and incident results.

## Variance and Learning

Compare planned versus actual scope, lead time, defects, cost, maintainer load, waivers, debt, user feedback, and ecosystem moderation.

## Actions

List corrective actions with owners and dates. Reconcile completed, deferred, rejected, discovered, deprecated, and retired roadmap work.

## Decision

Record whether the release remains supported, requires a patch, changes capability maturity, or triggers incident or deprecation governance.
