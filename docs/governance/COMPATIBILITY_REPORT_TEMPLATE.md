# Compatibility Report Template

## Metadata

Record component, contract version, Forgevena version, owner, verification date, evidence expiry, fixture revision, and live-test status.

## Matrix

| Environment or dependency | Tested version | Platform | Result | Limitations | Evidence |

## Contract and Data Use

Document supported capabilities, unsupported operations, authentication reference, network destination, data classifications, retry and idempotency behavior, policy controls, and redaction guarantees.

## Migration and Support

Record compatibility range, breaking changes, migration, rollback, support owner, next review date, and conditions that invalidate this report.
