# Frequently Asked Questions

## Does initialization overwrite my project?

No. It creates only missing assets and reports collisions as skipped.

## Are API keys written to profiles or the registry?

No. Profiles contain references only; masked setup stores ignored local or encrypted files.

## Why does a command only show a plan?

Modifying commands preview by default. Use `--apply`; external actions also require consent.

## Can rollback remove my edits?

No. It removes only unchanged, hash-matching managed files.

## Does the platform deploy automatically?

No. Credentials, billing approval, and explicit consent are required.
