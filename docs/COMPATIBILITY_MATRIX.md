# Compatibility Matrix

| Component | Supported |
| --- | --- |
| Node.js | 20.19 or newer |
| Operating systems | Windows, Linux/WSL, macOS |
| Architectures | npm: x64 and arm64; standalone v1.3.0 executables: x64 |
| Shell | PowerShell and direct Node invocation; external CLIs use argument arrays, not shell strings |
| Package | npm-compatible tarball with explicit allowlist plus checksum-verified Windows, Linux, and macOS x64 executables |
| Credentials | Environment references and encrypted project-local storage |

Live third-party compatibility depends on the installed official CLI/API and the user's account permissions.
