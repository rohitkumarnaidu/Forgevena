# Documentation Assets

This directory is reserved for reviewed, versioned documentation images and downloadable diagrams. Architecture diagrams currently use Mermaid source embedded in Markdown, which remains searchable, diffable, accessible, and theme-aware.

Do not add fabricated screenshots, unoptimized binaries, credentials, customer data, or third-party assets without verified redistribution rights and alt text.

Every image and SVG is declared in `visual-evidence.json` with accessible alternative text, product version, review dates, a content hash, and hashed source dependencies. An empty inventory is valid when no visual assets exist; an undeclared or stale asset blocks documentation validation.
