Forgevena governs project bootstrap, AI integrations, provider configuration, cloud preparation, and release engineering from idea to production.

npm install -g forgevena@1.3.0

brew install rohitkumarnaidu/forgevena/forgevena on Linux or Intel macOS.

Features

Additive

Existing files are never overwritten.

Governed

External actions preview scope and data impact.

Compatible

The legacy CLI and project state remain supported throughout 1.x.

Quick Start

forgevena doctor
forgevena create DemoApi --template fastapi --dry-run
forgevena init --dry-run
