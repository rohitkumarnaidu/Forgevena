# Version Support and LTS Policy

- Stable `1.x` receives security and critical correctness fixes for 18 months after the next major release.
- The latest minor release receives full maintenance; the previous minor receives critical fixes for six months.
- Release candidates receive validation support but no long-term guarantee.
- Node.js support follows maintained upstream LTS lines, with at least one minor-release deprecation notice before removal where security permits.
- Security fixes may require accelerated upgrades.
