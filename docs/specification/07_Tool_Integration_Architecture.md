# Tool Integration Architecture

Adapters classify upstream projects as CLIs, plugins, frameworks, or references. Each adapter exposes prerequisites, an official installation plan, dry-run output, version discovery, and project-scoped artifacts.

OpenSpec is a CLI; gstack and claude-mem are host integrations; SkillOpt is a Python workflow; GitNexus and Understand Anything are code-intelligence integrations; design.md and astryx are references.
