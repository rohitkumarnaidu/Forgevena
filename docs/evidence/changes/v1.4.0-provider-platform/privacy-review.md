# Privacy Review — Production Provider Platform

Prompts, responses, tool payloads, credentials, and authorization headers are `restricted`. Their default local retention is zero. Usage totals, provider IDs, model IDs, timings, normalized finish reasons, and stable error classes are operational metadata and follow configured retention.

No provider request runs during preview. Applied external requests require explicit consent describing provider, destination, data class, billing implications, and rollback limits. Diagnostics, logs, registries, fixtures, and compatibility evidence must not contain restricted content.
