# Capability Reference

Capabilities describe outcomes independently from upstream products.

| Capability | Integrations | Default |
|---|---|---|
| Specification management | OpenSpec | OpenSpec |
| Skill optimization | SkillOpt | SkillOpt |
| AI workflow | gstack | gstack |
| Design system | design.md, Astryx | design.md |
| Persistent memory | claude-mem | claude-mem |
| Code intelligence | GitNexus | GitNexus |
| Repository knowledge graph | Understand Anything | Understand Anything |

Use `ai-workspace capabilities` to inspect the mapping and `ai-workspace integrations status` to inspect project state. Capability resolution validates that a preferred integration implements the requested outcome.
