# Enterprise Adoption

- Pin platform and template versions.
- Require reviewed dry-run evidence for existing repositories.
- Centralize approved provider, MCP, plugin, and cloud policies.
- Store production credentials in enterprise secret managers.
- Protect branches, require cross-platform CI, and retain release evidence.
- Define data classification and provider egress rules before invocation.

Platform owners maintain releases, schemas, templates, and integrations. Security owners approve credentials, publishers, endpoints, and incident response. Project teams own source, provider use, deployment costs, and generated assets. Auditors consume registry, redacted logs, ADRs, and release reports.
