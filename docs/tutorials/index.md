# Tutorials

## Beginner

Run `doctor`; preview `create Demo --template fastapi --verbose`; apply it; enter the project; run `validate`, unit tests, and `docker validate`.

## Intermediate

Initialize a provider profile, configure its credential through masked input, set guarded limits, verify connectivity, and invoke only after reviewing data-egress policy. Follow the [provider reference](../providers/reference.md).

## Advanced

Register MCP and a plugin: validate TLS/schema, trust the publisher key, install declaratively, keep both disabled, then activate them for one host and run health checks. Follow [Plugins and MCP](../plugins/guide.md).

## Enterprise

Generate stack assets, validate containers and CI, generate the cloud blueprint, configure secret references in the cloud console, preview deploy and rollback plans, obtain billing approval, then execute with explicit consent.
