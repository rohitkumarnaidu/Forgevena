# Release Notes: 1.0.0

Version 1.0.0 establishes the stable enterprise and open-source baseline for AI Engineering Workspace.

## Stable Contracts

- Preview-first, additive project bootstrap and fourteen tested templates.
- Managed registry migrations, backups, upgrades, validation, and rollback.
- Governed credentials, providers, MCP servers, declarative plugins, cloud workflows, health, and diagnostics.
- Windows, Linux/WSL, and macOS packaging with npm, archives, Docker, Homebrew, Winget, Chocolatey, completions, and man page assets.
- Security, governance, LTS, compatibility, deprecation, contribution, incident, and release policies.

No external action executes without explicit consent. Existing user files remain protected.
