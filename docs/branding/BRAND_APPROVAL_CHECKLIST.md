# Brand Approval Checklist

- [ ] Professional trademark clearance completed in target jurisdictions/classes.
- [ ] GitHub organization and repository names reserved.
- [ ] npm and package-manager identifiers reserved.
- [ ] `.com`, `.dev`, `.io`, and defensive domain strategy approved.
- [ ] Social/community handles reviewed.
- [ ] Product word mark, pronunciation, caption, and brand story approved.
- [ ] CLI alias and deprecation period approved.
- [ ] Persisted-state migration deferred or approved with major-version policy.
- [ ] Repository/Pages redirect plan tested.
- [ ] ADR approved by maintainers and security/release owners.
- [ ] Rename branch, rollback owner, release window, and communication plan assigned.

Until every applicable item is complete, the current product identity remains authoritative.
