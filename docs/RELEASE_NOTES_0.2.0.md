# Release Notes: 0.2.0-rc.1

AI Engineering Workspace 0.2.0-rc.1 delivers a safety-first local developer platform for enterprise project bootstrap, provider configuration, credential management, governed MCP/plugins, cloud preparation and execution planning, health checks, upgrades, and release packaging.

## Highlights

- Fourteen additive project templates with stack-aware tests, Docker, CI, security, and documentation assets.
- Live provider execution paths with consent, retries, timeouts, budgets, and normalized responses.
- Encrypted/local credential lifecycle and secret-reference-only registries.
- Signed declarative plugin and governed MCP workflows.
- Loopback dashboard and multi-cloud preflight/execution paths.
- Managed rollback based on ownership and content hashes.
- Cross-platform npm packaging with explicit file allowlist.

Review `KNOWN_LIMITATIONS.md` before live external operations.
