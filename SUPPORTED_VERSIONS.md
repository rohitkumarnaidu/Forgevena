# Supported Versions

| Version | Support |
|---|---|
| 1.x | Security fixes and critical compatibility fixes |
| 0.x | Unsupported after the 1.0.0 stable release |

The latest 1.x minor receives full maintenance. Earlier 1.x minors receive critical security fixes when practical until superseded under the [LTS Policy](docs/LTS_POLICY.md). Node.js support follows `package.json` and the [Compatibility Matrix](docs/COMPATIBILITY_MATRIX.md).
