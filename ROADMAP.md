# Roadmap

Version 1.0.0 establishes the stable local-first developer platform: additive bootstrap, templates, integrations, providers, credentials, MCP/plugins, Docker/cloud preparation, dashboard, release packaging, and cross-platform verification.

Future work is evidence-driven and requires compatibility and architecture governance review. Candidate themes include more declarative adapters, enterprise secret-manager integrations, richer generated documentation sites, and expanded hosted validation.

See the detailed [Roadmap](docs/roadmap/index.md), [Future Roadmap](docs/v1/FUTURE_ROADMAP.md), and [Known Limitations](docs/KNOWN_LIMITATIONS.md).
