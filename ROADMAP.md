# Roadmap

Forgevena `v1.3.0` is the stable local-first reliability and security foundation. It provides additive bootstrap, governed integrations, encrypted credentials, state recovery, providers, MCP/plugins, templates, workflows, engineering intelligence, release packaging, and cross-platform verification.

The approved dependency sequence continues with provider maturity (`v1.4`), isolated plugin and MCP execution (`v1.5`), versioned template packages (`v1.6`), local organization governance (`v1.7`), observability and supply-chain evidence (`v1.8`), signed skills and deterministic workflows (`v1.9`), and local enterprise GA (`v1.10`). The optional remote control plane begins only at `v2.0`; ForgeRegistry, ForgeHub, and AI Engineering OS work follows the governed post-`v2.0` roadmap.

Roadmap changes require evidence, an RFC or ADR when applicable, security review, and an approved readiness scorecard. See the [public roadmap](docs/ROADMAP.md), [versioned product roadmap](docs/strategy/FORGEVENA_VERSIONED_PRODUCT_ROADMAP.md), [platform blueprint](docs/strategy/FORGEVENA_PLATFORM_BLUEPRINT.md), and [innovation opportunity portfolio](docs/strategy/INNOVATION_OPPORTUNITY_PORTFOLIO.md).
